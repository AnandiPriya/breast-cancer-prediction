# Breast Cancer Prediction using Machine Learning

# Project Overview

This project uses machine learning to predict whether a tumor is **malignant (cancerous)** or **benign (non-cancerous)** based on medical features.

#  Dataset

* Breast Cancer Wisconsin Dataset
* 569 patient records
* 30 features

#  Model Used

* Logistic Regression

# Results

* Accuracy: **95.6%**
* Confusion Matrix:

  ```
  [[70  1]
   [ 4 39]]
  ```

#Key Insights

* High accuracy in predicting cancer
* Very low false positives
* Few false negatives (important in healthcare)

# Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

# Conclusion

The model performs well in detecting breast cancer and can assist in early diagnosis.
